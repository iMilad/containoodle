Reuse an existing console session Offered during your first helper setup

When enabled, Containoodle can check whether this account's container is already signed in and reuse that session instead of starting another sign-in. It also suppresses the AWS cookie banner in new containers.

On your first local-helper Save & test, Firefox asks once for access limited to *.console.aws.amazon.com. Accepting enables session reuse; declining does not block setup or normal backend launches. Containoodle will not ask automatically again, but you can use Allow session reuse below. Revoking access stops future checks but does not delete cookies already managed by Firefox.

An older broad AWS grant keeps working until you explicitly tighten or revoke it. If Firefox says the broad grant still covers a narrower request, use Revoke, then Allow session reuse again. Opening Options, updating Containoodle, and switching modes do not migrate existing permissions.

How portal access is used

Containoodle copies your portal session cookie into the selected account container and verifies the copy before navigation. Optional sidebar role discovery sends that value directly to the AWS portal API. The value is never stored in extension storage or logged.

On the configured portal page, Containoodle reads the URL and displayed account name belonging to the console shortcut you click. It does not read forms, credentials, or the rest of the account list. Configuration stays in this Firefox profile.

Tab group names

By default, Containoodle uses the original account name. Optionally transform automatic group titles with a JavaScript regular expression.

Enter the pattern without /…/ delimiters. Leave it empty—or let it not match—to keep the original account name. Backtracking-prone constructs are rejected.

Use $1, $2, or named captures such as $<name>. An empty or overlong result falls back to the original name.

Saving changes future automatic updates. Resetting removes existing Containoodle group-title overrides and recalculates those titles from the account names and the saved rule. Container names, sidebar labels, and environment colours are unchanged.
